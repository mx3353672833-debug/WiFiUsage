# 流量账本 v1.1.0（build 2）

这一版新增应用内诊断与反馈，让问题更容易说明，也把数据何时留在本机、何时由你主动发送说得更清楚。

## 新增：诊断与反馈

- 在“设置”中新增“诊断与反馈”。
- 软件会在本机记录脱敏诊断事件，保留最近 7 天，合计最多占用 5 MiB。
- 可以直接打开日志位置、清除本地日志，或在应用内发送问题反馈。
- 诊断日志不会自动上传。选择附带日志后，可以在发送前预览具体内容。
- 联系方式与脱敏诊断日志是两个独立选项，只有分别明确选择后才会随反馈发送。
- 诊断记录覆盖数据库、Wi-Fi 识别、物理流量采样、应用用量采样、登录时启动和反馈发送等功能状态与错误代码。

## 数据与隐私边界

- 流量记录、套餐、Wi-Fi 分组和设置仍保存在本机，不进行云端同步。
- 软件不包含自动遥测、广告或后台日志上传。
- 每次发送应用内反馈时，都会发送问题描述、问题类型、软件版本与 build、macOS 版本和处理器架构。
- 只有选择“希望收到回复”后，联系方式才会发送。
- 只有选择“附带脱敏诊断日志”后，日志附件才会发送。
- 日志包含功能状态和错误代码。
- 日志不包含 Wi-Fi 名称、应用名称、文件路径、流量记录、套餐内容或联系方式。

本地数据位置：

```text
流量数据库：~/Library/Application Support/WiFiUsage/usage.sqlite
诊断日志：  ~/Library/Application Support/WiFiUsage/Logs/
```

## 主要功能

- 分别统计不同 Wi-Fi 的下载、上传和总用量。
- 连接切换后自动跟随当前 Wi-Fi。
- 为不同 Wi-Fi 绑定计费套餐，并估算基础费用、额度和超额费用。
- 查看今日、24 小时、7 天、本月和今年的趋势。
- 在本机估算各应用的 Wi-Fi 用量，支持低耗能和临时精细统计。
- 通过菜单栏快速查看用量，并支持登录时自动启动。

## 下载与安装

从官网下载 Universal DMG，支持 Apple Silicon 和 Intel Mac：

- 官网：<https://xjp.one/wifiusage/>
- DMG：<https://xjp.one/wifiusage/downloads/WiFiUsage-1.1.0-free.dmg>

```text
版本：1.1.0
build：2
文件：WiFiUsage-1.1.0-free.dmg
大小：2406265 bytes（2.4 MB）
SHA-256：aad32b364b5418948b34570adf1fd6cfadd874a740eb6d0b53d8aa2a0ab031b5
```

1. 打开 DMG，将 `WiFiUsage.app` 拖入“应用程序”。
2. 如果 macOS 首次阻止启动，请在“应用程序”中右键 WiFiUsage，选择“打开”；若仍被阻止，再到“系统设置”→“隐私与安全性”点“仍要打开”。
3. 打开后会自动识别当前 Wi-Fi，无需授予定位权限。

也可以下载本 Release 的 Source code（ZIP 或 TAR.GZ），按照仓库 README 从源码构建。

## 系统要求

- macOS 14 或更高版本
- Apple Silicon Mac 或 Intel Mac

## 已知限制

- 仅记录流量账本运行期间产生的流量。
- 同名 SSID 会合并为同一个 Wi-Fi。
- 应用流量属于本地估算，短连接、VPN、代理和系统服务可能无法完整识别。
- 应用排行暂不支持按 Wi-Fi 拆分。
- 套餐费用仅供参考，不代表运营商账单。
- 当前 DMG 尚未经过 Apple 公证，首次打开可能需要右键应用并选择“打开”。
